# Johnlene Lorenz R. Nael — Portfolio Website

**Johnlene Lorenz R. Nael**, a UI/UX Designer and Web Developer based in Daet, Camarines Norte, Philippines. Built with pure HTML, CSS, and JavaScript

## APIs & Their Purpose

### 1. EmailJS — `https://www.emailjs.com`
**Purpose:** Sends emails directly from the browser without a backend server.

### 2. Formspree — `https://formspree.io/f/mqedzvoj`
**Purpose:** Fallback for the contact form. If EmailJS fails, Formspree catches the submission and forwards it to the owner's email.

### 3. GitHub REST API — `https://api.github.com/users/johnlenenael`
**Purpose:** Fetches live GitHub profile data and displays it in the contact section.

### 4. Quotable API — `https://quotes-api-self.vercel.app/quote`
**Purpose:** Loads a random inspirational quote into the hero section on every page load.

### 5. Google Maps Embed API — `https://maps.google.com`
**Purpose:** Displays an embedded interactive map in the contact section showing the owner's location in Daet, Camarines Norte.

##  How to Run the Project

### Requirements
- A modern web browser (Chrome, Firefox, Edge, Safari)
- A local web server or a live hosting environment
- Your `resume.pdf` file (for the Download CV button)



### Option 1 — Run Locally with VS Code (Recommended)

1. **Download or clone the project files** into a folder on your computer

2. **Open the folder in VS Code.**

3. **Install the Live Server extension:**
   - Go to Extensions (`Ctrl+Shift+X`)
   - Search for `Live Server` by Ritwick Dey
   - Click Install

4. **Right-click `index.html`** in the file explorer → click **"Open with Live Server"**

5. Your browser will open at `http://127.0.0.1:5500` and the site will be live locally.
